# Mortgage Payment Calculator

A small, beginner-friendly web calculator for estimating a fixed-rate mortgage's:

- Monthly principal and interest payment
- Total of all payments
- Total interest paid over the life of the loan

## Open the calculator

Open `index.html` in any modern web browser. No installation or internet connection is required.

Enter the loan amount, annual interest rate, and loan term in years, then select **Calculate payment**.

> This calculator is an estimate. It does not include property taxes, homeowners insurance, mortgage insurance, HOA fees, or other costs.
